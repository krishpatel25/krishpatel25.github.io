Selected work

Three projects, moving down the stack — from the software that runs on a machine, to the machine itself, to the silicon it's printed on.

01

Out-of-Order RISC-V Processor

FLAGSHIP

A five-stage out-of-order RISC-V core. Reservation stations feed the execution units, a reorder buffer restores program order at commit, GShare predicts branches, and early recovery flushes a mispredicted path before it costs more cycles.

SystemVerilogVCS · VerdiVerilatorCoreMark
ISSUEOut-of-order
PREDICTORGShare
CACHE4-way SA
BENCHMARKCoreMark

The hard part wasn't issuing out of order — it was proving correctness. Directed tests for each hazard class, random instruction streams for the rest, and Verdi waveforms whenever the two disagreed.

02

391 Operating System

A UNIX-like operating system written from an empty file in embedded C — paging, an interrupt-driven keyboard driver, a read-only file system, terminal management, and round-robin scheduling across three concurrent terminals.

Cx86 AssemblyQEMU · GDB
TERMINALS3 concurrent

Writing a scheduler teaches you what a context switch actually costs — every register saved is a real store to real memory, and you feel it.
